# 神经网络部分 — 论述题知识点框架（手写参考）

## 第 1 题（10 分）
### 阐述人工智能、机器学习、神经网络、深度学习、感知机、多层感知机等概念，以及它们的区别和联系。

**一、概念定义**

1. **人工智能（Artificial Intelligence, AI）**
   - 最广泛的概念，指让机器模拟人类智能行为的科学与技术
   - 涵盖推理、学习、感知、规划、自然语言理解等领域
   - 早期代表：符号主义（专家系统）、连接主义（神经网络）

2. **机器学习（Machine Learning, ML）**
   - AI 的一个子领域，关注从数据中自动学习模式
   - 核心思想：不显式编程规则，而是让算法从数据中归纳
   - 主要范式：监督学习、无监督学习、强化学习

3. **神经网络（Neural Network, NN）**
   - 机器学习中受生物神经系统启发的计算模型
   - 由大量神经元（节点）通过加权连接构成
   - 最早的神经网络可追溯到 1943 年 McCulloch-Pitts 模型

4. **深度学习（Deep Learning, DL）**
   - 神经网络的子集，特指具有多层（深层）结构的神经网络
   - "深度"通常指两层以上的隐藏层
   - 代表模型：CNN（图像）、RNN/Transformer（序列）、GAN（生成）

5. **感知机（Perceptron）**
   - Rosenblatt 于 1958 年提出，是最简单的神经网络
   - 单层结构：输入层 → 一个输出神经元
   - 只能解决线性可分问题，是最简单的二分类模型

6. **多层感知机（Multilayer Perceptron, MLP）**
   - 在输入层和输出层之间加入一个或多个隐藏层
   - 每层神经元与下一层全连接
   - 使用非线性激活函数（如 sigmoid、ReLU），可解决非线性问题

**二、包含关系（从大到小）**

```
人工智能 ⊃ 机器学习 ⊃ 神经网络 ⊃ 深度学习
                                  ⊃ 多层感知机 (MLP)
                        ⊃ 感知机（最简单的神经网络）
```

**三、区别与联系**

- **AI vs ML**：AI 是目标，ML 是实现手段之一。AI 还包括非学习的符号推理
- **ML vs NN**：NN 是 ML 中的一类模型。ML 还包括决策树、SVM、贝叶斯等
- **NN vs DL**：DL 是 NN 的发展，强调"深度"。浅层 NN 不是 DL
- **感知机 vs MLP**：
  - 感知机无隐藏层、使用阶跃激活函数，只能线性分类
  - MLP 有隐藏层、使用非线性激活函数（sigmoid 等），可处理非线性问题
  - 感知机是 MLP 去掉隐藏层的特例
- **联系**：从感知机到 MLP 到深度学习，是一个"模型越来越深、表达能力越来越强"的演进过程。BP 算法的提出为 MLP 的训练奠定了基础，而算力和数据的发展催生了深度学习

## 第 2 题（20 分）
### 阐述感知机及其学习算法

**一、感知机的数学模型**

输入：特征向量 x = [x₁, x₂, ..., x_n]ᵀ
输出：二分类标签 y ∈ {-1, +1}

模型：
  f(x) = sign(w·x + b)

其中：
- w = [w₁, w₂, ..., w_n]ᵀ 为权重向量
- b 为偏置
- sign(a) = +1 (a ≥ 0), -1 (a < 0)

几何意义：w·x + b = 0 定义了 n 维空间中的一个超平面，
感知机将空间划分为两个半空间。

**二、感知机学习算法（原始形式）**

目标：找到能将训练集完全正确分类的超平面（假设数据线性可分）

策略：极小化误分类点到超平面的距离之和
损失函数：L(w, b) = -Σ y_i(w·x_i + b)，其中求和遍历所有误分类点

算法步骤：
1. 初始化 w ← 0, b ← 0
2. 遍历训练集，对每个样本 (x_i, y_i)：
   若 y_i(w·x_i + b) ≤ 0（即分类错误），则：
     w ← w + η·y_i·x_i
     b ← b + η·y_i
3. 重复步骤 2，直到所有样本正确分类或达到最大轮数

**三、收敛性分析（Novikoff 定理）**

若训练集线性可分，则：
- 存在超平面完美分离数据
- 感知机算法在有限步内收敛
- 误分类次数上界为 (R/γ)²，其中 R 为样本最大范数，γ 为分类间隔

若线性不可分：算法不收敛，表现为权重不断震荡

**四、感知机的局限性**

1. 只能解决线性可分问题（如无法解决 XOR 问题）
2. 对噪声敏感
3. 只给出一个可行解，不保证是最优分类面（对比 SVM 的最大间隔）
4. 不能输出概率形式的预测

**五、对偶形式**

w = Σ α_i·y_i·x_i, b = Σ α_i·y_i（对所有参与更新的样本求和）
分类决策：f(x) = sign(Σ α_i·y_i(x_i·x) + b)
优点：只需计算内积，可利用核技巧推广

## 第 3 题（20 分）
### 阐述多层感知机及 BP 算法、SGD 算法

**一、多层感知机（MLP）结构**

MLP = 输入层 + 一个或多个隐藏层 + 输出层，层间全连接

以单隐藏层 MLP 为例：
- 输入层：对原始特征不做变换
- 隐藏层：h = σ(W¹x + b¹)，σ 为非线性激活函数
- 输出层：ŷ = φ(W²h + b²)，φ 为输出激活函数（分类用 sigmoid/softmax）

关键要素：
1. **全连接**：相邻两层神经元两两连接
2. **非线性激活**：没有非线性激活的多层网络等价于单层
3. **深层结构**：可学习层次化的特征表示

常用激活函数：
- Sigmoid：σ(x) = 1/(1+e^{-x})，输出 (0,1)
- Tanh：tanh(x) = (e^x - e^{-x})/(e^x + e^{-x})，输出 (-1,1)
- ReLU：ReLU(x) = max(0, x)，缓解梯度消失

**二、BP（反向传播）算法**

BP 是训练 MLP 的核心算法，本质是链式法则的工程实现。

**核心思想**：
1. 前向传播计算每层的激活值
2. 从输出层开始，逐层反向计算损失对每层参数的梯度
3. 利用梯度更新参数

**数学推导**（以单隐藏层 + 均方误差损失为例）：

前向传播：
  z¹ = W¹x + b¹,   a¹ = σ(z¹)
  z² = W²a¹ + b²,  ŷ = σ(z²)
  L = (y - ŷ)²/2

反向传播（链式法则）：
  δ² = ∂L/∂z² = -(y - ŷ) · σ'(z²)        （输出层误差信号）
  δ¹ = ∂L/∂z¹ = (W²)ᵀδ² · σ'(z¹)          （隐藏层误差信号）

参数梯度：
  ∂L/∂W² = δ²(a¹)ᵀ,   ∂L/∂b² = δ²
  ∂L/∂W¹ = δ¹xᵀ,      ∂L/∂b¹ = δ¹

**BP 算法步骤**：
1. 前向传播：输入 x 通过网络，保存各层 z 和 a
2. 计算输出层误差 δᵏ
3. 对于 l = L-1, ..., 1：δˡ = (Wˡ⁺¹)ᵀδˡ⁺¹ ⊙ σ'(zˡ)
4. 计算各层参数梯度并更新

**三、SGD（随机梯度下降）算法**

**背景**：传统梯度下降每步需计算所有样本的梯度，计算量大

**三种梯度下降范式**：

| 方法 | 每步样本数 | 特点 |
|------|-----------|------|
| 批量 GD | 全部 N | 精确但慢、内存大 |
| SGD | 1 | 快但梯度噪声大、震荡 |
| Mini-batch SGD | B (如 32) | 平衡速度和稳定性 |

**Mini-batch SGD 算法**：
1. 每轮训练前随机打乱数据
2. 将数据分为大小为 B 的 mini-batch
3. 对每个 mini-batch：
   - 用 BP 计算该 batch 上的平均梯度
   - Wˡ ← Wˡ - η·∇_{Wˡ}L_batch
4. 重复多轮，逐步减小学习率（可选）

**SGD 的优点**：
- 计算效率高，适合大规模数据
- 梯度噪声有助于跳出局部最优
- 支持在线学习（流式数据）

**SGD 的改进**（选答，展示知识广度）：
- Momentum：累积历史梯度，加速收敛，减少震荡
  v_t = βv_{t-1} + (1-β)∇L,   θ ← θ - η·v_t
- Adam：结合 Momentum 和自适应学习率，目前最常用的优化器
- Learning rate schedule：阶梯衰减、指数衰减、余弦退火等

**四、MLP、BP、SGD 三者的关系**

- MLP 是模型（骨架），定义了网络的计算结构
- BP 是梯度的计算方式（链式法则），解决了"梯度怎么算"的问题
- SGD 是参数的更新策略，解决了"梯度往哪走"的问题
- 三者协同工作：MLP 前向计算 → BP 反向求梯度 → SGD 更新参数
