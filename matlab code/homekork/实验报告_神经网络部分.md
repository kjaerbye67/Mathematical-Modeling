## 一、二分类问题描述

### 1.1 问题来源

本实验选择**心形曲线（Cardioid）内外点分类**作为二分类问题。心形线是极坐标下的经典曲线，其数学定义简洁而几何形态优美，作为决策边界具有天然的非线性特性，适合用来检验线性分类器（感知机）与非线性分类器（MLP）的性能差异。

### 1.2 数学定义

在平面区域 $[-1.5, 1.5] \times [-2, 1]$ 内均匀随机采样 $n = 2000$ 个点。对每个采样点 $(x_1, x_2)$，定义标签 $y$：

- **正类（内部，$y = 1$）**：满足 $(x_1^2 + x_2^2 + x_2)^2 < x_1^2 + x_2^2$
- **负类（外部，$y = 0$）**：不满足上述不等式

该不等式的边界即为心形线 $(x_1^2 + x_2^2 + x_2)^2 = x_1^2 + x_2^2$，对应极坐标方程 $r = 1 - \sin\theta$。

### 1.3 问题特点

- 数据分布中，正类约占总样本的 51.2%，负类占 48.8%，类别相对均衡
- 决策边界为**非线性**光滑闭合曲线，无法用单一超平面（直线）分割
- 感知机作为线性分类器，理论上无法取得超过约 50% 的准确率
- MLP 借助隐藏层的非线性激活函数，可以逼近任意形状的决策边界

### 1.4 创新点

区别于常见的 XOR 问题或双月形数据集，心形曲线分类在以下方面具有新意：
1. 决策边界由经典的数学曲线定义，具有明确的几何意义
2. 边界非线性程度可量化，便于理论分析
3. 可视化效果直观美观，有助于理解分类器行为

## 二、算法描述

### 2.1 感知机（Perceptron）

感知机是 Rosenblatt 于 1958 年提出的线性二分类模型。

**模型形式**：$\hat{y} = \text{sign}(\mathbf{w}^T \mathbf{x} + b)$

**学习算法**：
1. 初始化权重 $\mathbf{w} = \mathbf{0}$（或小随机值），偏置 $b = 0$
2. 对每个训练样本 $(\mathbf{x}_i, y_i)$（其中 $y_i \in \{-1, +1\}$）：
   - 若 $\text{sign}(\mathbf{w}^T \mathbf{x}_i + b) \neq y_i$，则更新：
     - $\mathbf{w} \leftarrow \mathbf{w} + \eta \cdot y_i \cdot \mathbf{x}_i$
     - $b \leftarrow b + \eta \cdot y_i$
3. 重复直到所有样本分类正确或达到最大迭代次数

**收敛性**：若数据集线性可分，感知机在有限步内收敛；若线性不可分，则无法收敛。

### 2.2 多层感知机（MLP）及 BP 算法

本实验采用**单隐藏层 MLP**，网络结构为 $2 \rightarrow h \rightarrow 1$。

**前向传播**：
$$\mathbf{z}^{(1)} = \mathbf{X}\mathbf{W}^{(1)} + \mathbf{b}^{(1)}, \quad \mathbf{a}^{(1)} = \sigma(\mathbf{z}^{(1)})$$
$$\mathbf{z}^{(2)} = \mathbf{a}^{(1)}\mathbf{W}^{(2)} + b^{(2)}, \quad \hat{\mathbf{y}} = \sigma(\mathbf{z}^{(2)})$$

其中 $\sigma(x) = \frac{1}{1 + e^{-x}}$ 为 sigmoid 激活函数。

**损失函数**（二分类交叉熵）：
$$\mathcal{L} = -\frac{1}{m}\sum_{i=1}^{m}\left[y_i \log(\hat{y}_i) + (1-y_i)\log(1-\hat{y}_i)\right]$$

**BP 反向传播**（链式法则）：
- 输出层梯度：$\delta^{(2)} = \hat{\mathbf{y}} - \mathbf{y}$（交叉熵 + sigmoid 的合并梯度）
- 隐藏层梯度：$\delta^{(1)} = \delta^{(2)}(\mathbf{W}^{(2)})^T \odot \sigma'(\mathbf{z}^{(1)})$
- 参数梯度：$\nabla_{\mathbf{W}^{(2)}}\mathcal{L} = (\mathbf{a}^{(1)})^T\delta^{(2)} / m$, $\nabla_{\mathbf{W}^{(1)}}\mathcal{L} = \mathbf{X}^T\delta^{(1)} / m$

### 2.3 SGD 优化算法

采用 mini-batch SGD：
$$\mathbf{W}^{(l)} \leftarrow \mathbf{W}^{(l)} - \eta \cdot \nabla_{\mathbf{W}^{(l)}}\mathcal{L}_{\text{batch}}$$

其中 $\eta$ 为学习率，batch_size = 32。每轮训练前随机打乱数据，确保梯度估计的无偏性。

## 四、运行结果及分析

### 4.1 分类准确率

| 模型 | 训练准确率 | 测试准确率 |
|------|-----------|-----------|
| 感知机 | 51.88% | 50.75% |
| MLP（30隐藏层） | 97.69% | 96.75% |

### 4.3 结果分析

**感知机结果分析**：
- 感知机的训练和测试准确率均约为 50%，等价于随机猜测
- 根本原因：感知机只能学习**线性决策边界**（二维平面中的一条直线），而心形曲线是高度非线性的闭合曲线。无论直线如何放置，都会将约一半的内部点和一半的外部点错误分类
- 该结果印证了感知机的理论局限：对于线性不可分的数据集，感知机算法不收敛

**MLP 结果分析**：
- MLP 测试准确率达到 96.75%，说明模型成功逼近了心形决策边界
- 隐藏层 30 个神经元配合 sigmoid 激活函数，提供了足够的非线性表达能力
- 剩余的约 3% 误差主要分布在心形边界附近，因为边界处采样点稀疏且曲率变化大
- 训练集和测试集准确率接近（97.69% vs 96.75%），无明显过拟合

**对比结论**：
1. 感知机作为单层线性模型，无法处理非线性可分问题
2. MLP 通过引入隐藏层和非线性激活函数，具备通用逼近能力（Universal Approximation Theorem）
3. BP 算法 + SGD 能够有效地训练多层神经网络，学习复杂的非线性映射
4. 本实验直观验证了"深度学习相比浅层模型的表达能力优势"这一核心思想

### 4.4 超参数影响讨论

- **隐藏层神经元数**：实验发现 h=30 效果良好。神经元过少（如 h=5）时模型表达能力不足、准确率下降；过多（如 h=100）时无明显提升但计算量增大
- **学习率**：$\eta = 0.1$ 在本实验中收敛稳定。过大可能导致损失震荡，过小则收敛缓慢
- **训练轮数**：500 轮足够模型收敛，损失曲线在约 300 轮后趋于平稳
