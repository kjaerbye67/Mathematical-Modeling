## 一、二分类问题描述

### 1.1 问题选型

本实验选择**心形曲线（Cardioid）内外点分类**作为二分类问题。心形线是极坐标下的经典曲线，其数学定义简洁而几何形态优美，作为决策边界具有天然的非线性特性，非常适合检验线性分类器（感知机）与非线性分类器（MLP）的性能差异。

### 1.2 数学定义

在平面区域 $[-1.5, 1.5] \times [-2, 1]$ 内均匀随机采样 $n = 2000$ 个点。对每个采样点 $(x_1, x_2)$：

- **正类（内部，$y = 1$）**：满足 $(x_1^2 + x_2^2 + x_2)^2 < x_1^2 + x_2^2$
- **负类（外部，$y = 0$）**：不满足上述不等式

该不等式的边界为心形线 $(x_1^2 + x_2^2 + x_2)^2 = x_1^2 + x_2^2$，对应极坐标方程 $r = 1 - \sin\theta$。

### 1.3 问题特点与创新点

- 决策边界为**非线性**光滑闭合曲线，无法用单一直线分割
- 心形曲线是经典数学曲线，具有明确的几何意义，区别于常见的 XOR、双月形等示例
- 可视化直观美观，便于理解分类器行为

## 二、算法描述

### 2.1 感知机（Perceptron）

**模型**：$\hat{y} = \text{sign}(\mathbf{w}^T \mathbf{x} + b)$，其中 $\text{sign}(a) = +1\ (a \ge 0), -1\ (a < 0)$

**学习算法**：
1. 初始化 $\mathbf{w}$ 为小随机值，$b = 0$
2. 对每个训练样本 $(\mathbf{x}_i, y_i)$（$y_i \in \{-1, +1\}$）：
   - 若 $\text{sign}(\mathbf{w}^T \mathbf{x}_i + b) \neq y_i$，更新：
     - $\mathbf{w} \leftarrow \mathbf{w} + \eta \cdot y_i \cdot \mathbf{x}_i$
     - $b \leftarrow b + \eta \cdot y_i$
3. 每轮随机打乱数据，重复直到收敛或达到最大轮数

**收敛性**：仅当数据线性可分时收敛；线性不可分时算法不收敛。

### 2.2 多层感知机（MLP）与 BP 算法

网络结构：$2 \to h \to 1$（输入 2 维，隐藏层 $h$ 个神经元，输出 1 维）

**前向传播**：
- $\mathbf{z}^{(1)} = \mathbf{X}\mathbf{W}^{(1)} + \mathbf{b}^{(1)},\ \mathbf{a}^{(1)} = \sigma(\mathbf{z}^{(1)})$
- $\mathbf{z}^{(2)} = \mathbf{a}^{(1)}\mathbf{W}^{(2)} + b^{(2)},\ \hat{\mathbf{y}} = \sigma(\mathbf{z}^{(2)})$

其中 $\sigma(x) = \frac{1}{1 + e^{-x}}$ 为 sigmoid 激活函数。

**损失函数**（二分类交叉熵）：
$$\mathcal{L} = -\frac{1}{m}\sum_{i=1}^{m}\left[y_i \log(\hat{y}_i) + (1-y_i)\log(1-\hat{y}_i)\right]$$

**BP 反向传播**：
- 输出层误差信号：$\delta^{(2)} = \hat{\mathbf{y}} - \mathbf{y}$（交叉熵 + sigmoid 的合并梯度）
- 隐藏层误差信号：$\delta^{(1)} = \delta^{(2)}(\mathbf{W}^{(2)})^T \odot \sigma'(\mathbf{z}^{(1)})$
- 权重梯度：$\nabla_{\mathbf{W}^{(2)}}\mathcal{L} = \frac{1}{m}(\mathbf{a}^{(1)})^T\delta^{(2)}$，$\nabla_{\mathbf{W}^{(1)}}\mathcal{L} = \frac{1}{m}\mathbf{X}^T\delta^{(1)}$

### 2.3 Mini-batch SGD

每轮随机打乱数据，以 batch_size = 32 分组，对每组计算平均梯度后更新：
$$\mathbf{W} \leftarrow \mathbf{W} - \eta \cdot \nabla_{\mathbf{W}}\mathcal{L}_{\text{batch}}$$

## 三、可运行代码

代码由三个 `.py` 文件组成，仅依赖 `numpy` 和 `matplotlib`：

| 文件 | 说明 |
|------|------|
| `perceptron_classifier.py` | 感知机二分类器，SGD 训练 |
| `mlp_classifier.py` | MLP 分类器，含 BP 反向传播 + Mini-batch SGD |
| `binary_classification_experiment.py` | **主实验脚本**，运行此文件即可生成全部结果和图片 |

**运行方式**：
```bash
python3 binary_classification_experiment.py
```

**关键参数**：

| 参数 | 感知机 | MLP |
|------|--------|-----|
| 学习率 $\eta$ | 0.01 | 0.1 |
| 训练轮数 | 200 | 500 |
| 隐藏层神经元 | — | 30 |
| Batch size | 全量 | 32 |
| 数据划分 | 80% 训练 / 20% 测试 | 同左 |
| 特征预处理 | 标准化（zero mean, unit std） | 同左 |

## 四、运行结果及分析

### 4.1 分类准确率

| 模型 | 训练准确率 | 测试准确率 |
|------|-----------|-----------|
| 感知机 | 48.06% | 48.50% |
| MLP（30隐藏层） | 97.75% | 97.75% |

### 4.2 结果分析

**感知机**：
- 准确率 ≈ 50%，等价于随机猜测
- 原因：感知机只能学习线性决策边界（二维平面中的一条直线），而心形曲线是高度非线性的闭合曲线，无法用直线分离

**MLP**：
- 测试准确率高达 97.75%，成功逼近心形决策边界
- 隐藏层 30 个神经元 + sigmoid 激活函数提供了足够的非线性表达能力
- 训练/测试准确率几乎一致（97.75% vs 97.75%），无过拟合
- 剩余误差主要分布在心形边界尖点处

**对比结论**：
1. 感知机作为线性分类器，无法处理非线性可分问题
2. MLP 通过隐藏层 + 非线性激活函数，具备通用逼近能力
3. BP + SGD 能有效训练 MLP，学习复杂的非线性映射
4. 本实验直观验证了深度学习"多层非线性变换"的核心优势
